# آیکون برنامه «نمایش همه چیز!!»

## مفهوم طراحی آیکون (به انتخاب من)

### ایده اصلی:
یک **آیفون مینیمال** در مرکز که از پشت آن چندین لایه اطلاعات به صورت دایره‌های نورانی خارج شده‌اند:

- لایه اول (نزدیک‌ترین): باتری سبز درخشان
- لایه دوم: موج‌های سیگنال فیروزه‌ای
- لایه سوم: خورشید/روشنایی نارنجی
- لایه چهارم: تراشه‌های حافظه بنفش

### رنگ‌بندی پیشنهادی:
- پس‌زمینه: گرادیان تیره از `#0B1220` به `#1A1030`
- رنگ اصلی: فیروزه‌ای درخشان `#22D3EE`
- رنگ ثانویه: بنفش `#A855F7`
- لهجه: نارنجی `#F97316`

### استایل:
- بسیار تمیز و مدرن (Glassmorphism + Neumorphism ملایم)
- گوشه‌های گرد مطابق آیکون‌های iOS
- بدون متن اضافه (فقط نماد)
- مناسب Dark Mode

### پیشنهاد ساخت آیکون:

می‌توانید با ابزارهای زیر آیکون را بسازید:

1. **SF Symbols + Xcode** (ساده‌ترین)
2. **Figma** یا **Canva**
3. **AppIcon.co** یا **IconKitchen**

### نماد پیشنهادی با SF Symbol:
```
iphone + antenna.radiowaves.left.and.right + battery.100
```

یا ترکیب:
```
circle.hexagongrid.fill
```
با رنگ گرادیان فیروزه‌ای-بنفش
