# نمایش همه چیز!!

اپلیکیشن زیبا و مدرن iOS برای نمایش اطلاعات سیستم دستگاه.

## قابلیت‌ها

### 🔋 باتری
- درصد باتری
- وضعیت شارژ (در حال شارژ / پر / در حال استفاده)
- حالت Low Power Mode

### 💡 نمایشگر
- کنترل روشنایی صفحه (کم و زیاد کردن)
- نمایش درصد روشنایی فعلی

### 📡 ارتباط و شبکه
- نوع اتصال (Wi-Fi / Cellular / بدون اتصال)
- نام شبکه Wi-Fi (در صورت دسترسی)
- نوع شبکه سلولی (4G / 5G / LTE و ...)

### 📱 اطلاعات دستگاه
- مدل دستگاه
- نسخه iOS
- نام دستگاه
- شناسه سیستم

### 💾 ذخیره‌سازی
- فضای کل
- فضای استفاده شده
- فضای آزاد

### 🧠 حافظه
- حافظه کل
- حافظه استفاده شده تقریبی

## نکات مهم

- برخی اطلاعات مثل **قدرت دقیق سیگنال** و جزئیات سیم‌کارت به دلیل محدودیت‌های اپل (Private API) در اپ‌های معمولی قابل دسترسی نیستند.
- کنترل روشنایی فقط وقتی اپ در پیش‌زمینه است کار می‌کند.

## اجرا

پروژه را با Xcode 15+ باز کنید و روی شبیه‌ساز یا دستگاه واقعی اجرا کنید.
